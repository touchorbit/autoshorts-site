# AutoShorts public website

Static GitHub Pages website for the AutoShorts TikTok developer application.

## Pages
- `/` — Official website / product description
- `/privacy/` — Privacy Policy
- `/terms/` — Terms of Service

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `autoshorts-site`.
2. Upload all files and folders from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After deployment, the site should be available at:
   `https://touchorbit.github.io/autoshorts-site/`

TikTok form URLs:
- Official website: `https://touchorbit.github.io/autoshorts-site/`
- Privacy Policy: `https://touchorbit.github.io/autoshorts-site/privacy/`
- Terms of Service: `https://touchorbit.github.io/autoshorts-site/terms/`

## TikTok URL verification
When TikTok gives you a verification/signature file, upload that exact file to the required repository path. Do not rename or modify it.
